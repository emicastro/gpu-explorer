---
id: l2
does: "The cache shared by every SM, between them and HBM."
stores: "Data recently read from or written to [[hbm]], including weights and KV that several blocks want."
---

Every byte that reaches an [[sm]] from [[hbm]] passes through it, so the traffic of a kernel is the same at both. If a weight tile is used by several blocks, only the first pays the trip to memory. See [[l2-cache]].
